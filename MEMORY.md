# MEMORY.md

## Package State

- This is a topic-neutral research skills package.
- No specific user's project, material system, device stack, measured result, literature claim, or local lab setup should be stored here by default.
- Topic-specific facts must be added only after the installing user configures their own project and explicitly asks to remember durable information.

## Default Behavior

- Use `PROJECT_VARIABLES.md` as the first source for project-specific context.
- If a required project variable is unset, ask the user to provide it instead of making assumptions.
- Treat examples as templates only; do not interpret placeholder values as real project facts.
- Keep all skill installations and generated files project-local unless the user explicitly requests another target.

## Memory Maintenance

- Long-term facts belong in this file only after user confirmation.
- Daily notes belong in `memory/YYYY-MM-DD.md`.
- Store durable configuration changes, validated parameter sets, data-processing decisions, and persistent user preferences here.
- Do not import legacy or source-workspace memories into a new user's installed project.
